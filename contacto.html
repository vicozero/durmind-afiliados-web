Consultas y soporte

El canal de contacto disponible es la sección Issues del repositorio del sitio. Puedes iniciar una consulta sobre el proyecto, informar de un error o solicitar contacto sobre privacidad.

Antes de escribir

Las consultas de GitHub Issues son públicas y pueden requerir una cuenta de GitHub. No publiques contraseñas, tokens, documentos de identidad, referencias de pedido, importes ni datos personales sensibles. Para una consulta privada, inicia el contacto indicando únicamente que necesitas un canal privado; el responsable acordará el medio apropiado.

Sobre las integraciones

La versión actual funciona localmente y las publicaciones son manuales. La integración con Pinterest sigue en desarrollo. Este sitio no ofrece activaciones pagadas ni garantiza ingresos.
