Política de privacidad

Sitio informativo y ediciones local y web de DURMIND Afiliados.

Última actualización: 4 de noviembre de 2026.

1. Responsable y alcance

Victor Alberto, titular del proyecto DURMIND Afiliados y de la cuenta de GitHub vicozero, administra este sitio. Puedes comunicarte mediante el canal de contacto del proyecto.

Esta política describe el sitio público alojado en GitHub Pages, la aplicación local y el panel privado en la nube. El sitio informativo no es el panel de gestión ni ofrece registro de usuarios. El panel web requiere iniciar sesión con la cuenta autorizada por el alojamiento.

2. Datos al visitar esta web

Este sitio no incorpora formularios, herramientas de analítica, publicidad, píxeles de seguimiento ni cookies propias. Sus archivos se sirven desde GitHub Pages; no se cargan fuentes, scripts o imágenes de terceros.

GitHub puede registrar información técnica de las visitas, incluidas direcciones IP, para operar y proteger el servicio. Ese tratamiento está sujeto a la declaración de privacidad de GitHub. El responsable de DURMIND no controla los plazos de conservación del proveedor.

3. Datos de la aplicación local

La aplicación almacena en una base SQLite del equipo del operador los productos y enlaces introducidos, notas, borradores, fechas editoriales, estados de publicación y registros manuales de comisiones, que pueden incluir referencias de pedido. La finalidad es organizar contenido y llevar un registro de resultados declarados por el operador.

El archivo local de configuración contiene una clave de sesión y el hash de la contraseña del panel. La aplicación utiliza una cookie de sesión para mantener el acceso y proteger formularios. No necesita ni almacena las contraseñas de Pinterest o Mercado Libre.

La aplicación no envía estos registros al sitio público ni extrae automáticamente información de Mercado Libre. El módulo opcional de Pinterest solo consulta datos tras una autorización expresa. Los archivos exportados o las copias de seguridad quedan bajo control de quien los crea.

3.1. Panel privado en la nube

La edición web utiliza Sites y Cloudflare Workers con una base D1 persistente. A diferencia de la edición local, sus registros se guardan en el servidor y pueden consultarse desde dispositivos autorizados aunque la computadora del titular esté apagada. No se transfieren automáticamente las bases SQLite del equipo.

El acceso es privado y utiliza la identidad de la cuenta de ChatGPT. El alojamiento proporciona un identificador, nombre y correo de sesión. La aplicación utiliza el identificador para separar los registros del usuario; el nombre o correo se usa para mostrar la sesión, sin guardarlo en las tablas de productos, borradores o comisiones.

En la base se guardan los productos, enlaces, notas, precios manuales, textos de borradores, fechas editoriales y registros manuales de comisiones. La finalidad es organizar contenido y consultar resultados declarados. Los CSV importados se procesan para incorporar productos; no se conserva el archivo original. Las imágenes PNG, paquetes ZIP y exportaciones se generan o descargan en el navegador; no se almacenan como archivos en el servidor.

La versión cloud no tiene conectados OAuth de Pinterest, publicación automática, métricas externas ni captura de comisiones. No contiene claves de Pinterest o Mercado Libre. La preparación OAuth descrita en el apartado 4 corresponde al módulo local opcional.

Los registros cloud no tienen un plazo de borrado automático. El usuario puede exportar los registros cargados, hasta 1.000 por sección; la versión actual no incorpora restauración JSON ni un botón de eliminación completa. Las solicitudes de acceso, corrección o eliminación pueden iniciarse mediante el canal de contacto sin publicar datos sensibles.

Los proveedores de alojamiento e identidad pueden tratar información técnica y cookies necesarias para prestar y proteger sus servicios, conforme a las políticas de OpenAI y Cloudflare. La aplicación no utiliza esos registros para publicidad ni incorpora analítica propia.

4. Conexión opcional con Pinterest

El acceso Trial de la aplicación está pendiente según la última comprobación del titular. Se ha preparado un módulo de OAuth de solo lectura; no se ha verificado una conexión real ni se ha habilitado publicación automática.

Si Pinterest habilita el acceso y el titular inicia voluntariamente la conexión desde su PC, la aplicación solicita únicamente los permisos boards:read y pins:read. Pinterest recibe la solicitud y, tras la autorización, devuelve un código que el servidor local intercambia por un token. La clave de la aplicación se configura en el equipo del titular; no se publica ni se envía a esta web.

El token de acceso se conserva solo en memoria del servidor hasta su vencimiento, desconexión local o reinicio. El código de autorización se usa una vez y no se conserva intencionadamente. No se guarda el token de renovación, no hay renovación automática y los tokens no se almacenan en SQLite, cookies, exportaciones ni en este sitio.

El módulo puede mostrar hasta 25 tableros de la cuenta autorizada por consulta; no guarda ese listado en la base local. El botón de desconexión retira el token de memoria. Para revocar también los permisos en Pinterest, el titular debe hacerlo desde las opciones de aplicaciones conectadas de ese servicio. Las futuras funciones de publicación o métricas adicionales requerirán actualizar esta política y obtener los permisos correspondientes antes de activarse.

5. Compartición y enlaces externos

DURMIND no vende los datos de la aplicación local ni los utiliza para publicidad dirigida. Cuando el operador publica contenido o comparte un archivo exportado, transmite su contenido al servicio o destinatario que elija. Esas acciones son independientes de la visita a esta web.

Pinterest, Mercado Libre y GitHub son servicios independientes con sus propias políticas. Abrir un enlace externo puede comunicar datos técnicos al destino.

6. Conservación, acceso y eliminación

Los registros locales permanecen en el equipo hasta que su operador los modifique o elimine; la versión actual no aplica un plazo de borrado automático. El operador puede consultar sus registros y exportarlos en CSV. La eliminación completa de los datos locales requiere cerrar la aplicación y retirar su base y las copias o exportaciones que se quieran eliminar. No existe aún un botón de borrado completo. Si se ha habilitado la conexión opcional con Pinterest, puede desconectarse como se explica en el apartado 4.

Si consideras que el proyecto trata datos personales tuyos, usa el canal de contacto para solicitar información, acceso, corrección o eliminación, según corresponda. Inicia el contacto sin publicar información sensible; se acordará un medio adecuado si hace falta verificar o tratar tu solicitud.

7. Seguridad

El panel utiliza contraseña con hash y protección de formularios. La configuración de red local actual usa HTTP y debe limitarse a una red privada de confianza. El sitio informativo no expone la base, la configuración ni el servidor Flask del operador. El panel cloud utiliza HTTPS, acceso privado y comprobaciones del propietario de los registros en el servidor. Ningún sistema ofrece seguridad absoluta.

8. Cambios

Los cambios se publicarán en esta página con una nueva fecha. Cualquier integración futura deberá reflejar su funcionamiento real en esta política antes de activarse.
