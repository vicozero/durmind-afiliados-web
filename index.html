LA HERRAMIENTA

Menos piezas sueltas.
Más orden para tu contenido.

El panel web de DURMIND Afiliados guarda tus registros en la nube. Puedes trabajar desde Windows o tu teléfono con acceso a internet, aunque tu computadora esté apagada. La versión local sigue disponible por separado.

01 / PRODUCTOS

Tu selección, organizada

Guarda nombres, categorías, notas propias y enlaces de afiliado introducidos manualmente. Los precios son opcionales y requieren revisión.

02 / BORRADORES

Una base para crear

Genera textos mediante plantillas y diseños PNG con Pillow. Revisa cada borrador y descarga un ZIP con imagen y texto para su publicación manual.

03 / RESULTADOS

Cifras con contexto

Registra manualmente comisiones pendientes, confirmadas o rechazadas a partir de tu portal oficial. Exporta la información en CSV.

SIGUIENTE ETAPA

Pinterest, con autorización.

Estamos preparando una integración para publicar contenido seleccionado y consultar métricas de la cuenta autorizada mediante la API oficial.

Su disponibilidad depende de la implementación, el acceso que apruebe Pinterest y la autorización del titular. La versión cloud no publica automáticamente, no tiene OAuth conectado y no consulta métricas de Pinterest.
